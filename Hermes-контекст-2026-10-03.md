## 6. Ловушки и уроки
- Hermes **не перезапускает gateway изнутри** — всегда `hermes gateway restart` по SSH (Termius).
- Конфиг — только через `hermes config set`. Ключи вне схемы (`tools.tool_search`, `tool_budget.mcp_result_size_chars`) — с `--force`. Предупреждения «not a recognized key» для `agent.reasoning_effort`, `auxiliary.*.fallback_chain`, `max_concurrency`, `background_review.max_input_tokens` ложные: рантайм эти ключи читает.
- Hermes **не видит** сообщения, которые ты отправлял мне: YAML надо вставлять ему целиком.
- Не вставлять чужие списки `disabled_toolsets`: они заменяют текущий список, а не дополняют.
- Изменения toolsets и схем инструментов применяются только после рестарта gateway; `compression.*` — со следующего сообщения.
- Смена модели посреди сессии сбрасывает кэш промпта.
- Stealth-модели не использовать для клиентских данных и cron.
- Свободная RAM «free» почти всегда мала — смотреть на «available».

### 1.3 Настройка Conduit по шагам

**Шаг 1. Как добраться до VPS с телефона.** Выберите один вариант.

| Способ | Плюсы | Минусы |
|---|---|---|
| **A. Tailscale** (рекомендуется) | Шифрование, ничего не торчит в интернет. Conduit официально поддерживает HTTP по адресам `100.x` и `.ts.net` | ⚠️ В iOS одновременно работает **только один VPN**. Если вы держите другой VPN для обхода блокировок, они будут конфликтовать. Процесс `tailscaled` занимает около 30–50 МБ RAM ⚠️ |
| **B. Домен + HTTPS + Nous OAuth** | Не занимает VPN-слот на iPhone | Сложнее. По документации пароль на дашборде допустим **только в доверенной сети или за VPN**, а для публичного доступа нужен OAuth через `hermes dashboard register` ✅ |

Документация: дашборд на не-loopback адресе обязательно требует авторизацию, а `--insecure` больше её не отключает ✅ (https://hermes-agent.nousresearch.com/docs/user-guide/features/web-dashboard?format=md).

**Шаг 2. Команды на VPS** (вариант A):

```bash
# Tailscale
curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up            # откроет ссылку для входа
tailscale ip -4              # запомните адрес 100.x.y.z

# Логин для дашборда (если ещё не задан)
cat >> ~/.hermes/.env <<'EOF'
HERMES_DASHBOARD_BASIC_AUTH_USERNAME=admin
HERMES_DASHBOARD_BASIC_AUTH_PASSWORD=СЛОЖНЫЙ_ПАРОЛЬ
EOF
echo "HERMES_DASHBOARD_BASIC_AUTH_SECRET=$(openssl rand -base64 32)" >> ~/.hermes/.env
chmod 600 ~/.hermes/.env

# Дашборд слушает только адрес в Tailscale (используйте свой systemd-юнит)
hermes dashboard --host 100.x.y.z --port 9119 --no-open

# Push-уведомления для Conduit
hermes plugins install kaishi00/hermes-conduit-notifier --enable
hermes gateway restart
```

Ключи `HERMES_DASHBOARD_BASIC_AUTH_*` и привязка к адресу Tailscale — из документации ✅ (https://hermes-agent.nousresearch.com/docs/user-guide/features/web-dashboard?format=md). Плагин уведомлений — из README Conduit (https://github.com/kaishi00/hermes-conduit). Обратите внимание: `$(openssl …)` нужно выполнять именно в shell. Hermes читает `.env` без подстановок, поэтому вставленный как текст `$(openssl …)` станет буквальным секретом (https://github.com/goncharik/hermes-mobile).

**Шаг 3. На iPhone:**
1. Поставить Tailscale из App Store и войти тем же аккаунтом.
2. Поставить Hermes Conduit.
3. Адрес сервера: `http://100.x.y.z:9119`, логин `admin` и ваш пароль.
4. Settings → Notifications → пройти сопряжение.
5. В настройках голоса выбрать **серверное распознавание (Whisper)**, а не распознавание на устройстве. На устройстве работает тот же движок Apple, что и в плохой для вас диктовке ⚠️ (точное название пункта меню сверьте в приложении).

**Шаг 4. Сообщение для Hermes, чтобы он всё сделал сам:**

```text
Задача: подготовить VPS для iOS-клиента Hermes Conduit.
1) Проверь: как сейчас запущен дашборд (systemd/tmux), на каком host:port, включена ли авторизация (curl -s http://127.0.0.1:9119/api/status | jq '.auth_required, .auth_providers' или аналог).
2) Установи Tailscale, если его нет (curl -fsSL https://tailscale.com/install.sh | sh), выполни tailscale up и пришли мне ссылку для входа. После входа сообщи tailscale ip -4.
3) Если нет логина дашборда — добавь в ~/.hermes/.env HERMES_DASHBOARD_BASIC_AUTH_USERNAME=admin, сгенерируй сложный пароль и SECRET через openssl в shell, chmod 600. Пароль пришли мне один раз.
4) Перенастрой systemd-юнит дашборда: --host <tailscale-ip> --port 9119 --no-open, Restart=always, EnvironmentFile=%h/.hermes/.env. Перезапусти, проверь, что порт 9119 НЕ слушается на публичном IP (ss -tlnp).

## 2. Как разделить много тем и направлений

### 2.1 Уровни изоляции

| Уровень | Что отделяет | Цена (RAM / токены) | Когда использовать |
|---|---|---|---|
| **Профиль** (`hermes -p`) | Свои `config.yaml`, `.env`, SOUL.md, память, сессии, навыки, cron, state.db ✅ | С v0.21 один gateway обслуживает **все** профили (мультиплексирование включено по умолчанию), поэтому отдельный процесс не нужен ✅. Каждый профиль — это ещё один набор памяти и навыков, который надо поддерживать | Нужны **другая память, персона или ключи**: работа отдельно от личного |
| **Проект** (`hermes project`) | Именованное рабочее пространство из папок. Группирует сессии ✅ | 0 | Направление внутри профиля: сметы, КП, сайт… |
| **AGENTS.md в папке проекта** | Правила направления. Подгружается из рабочей папки при старте сессии ✅ | Его размер в токенах на каждом запросе | Короткие постоянные правила направления |
| **Навык (skill)** | Процедура или шаблон. В промпте только строка в индексе, полный текст загружается по требованию ✅ | Мало | Повторяемые задачи: смета, КП, отчёт |
| **Сессия** | Одна переписка | История | Одна задача или одна неделя рутины |

Источники: профили ✅ (https://hermes-agent.nousresearch.com/docs/user-guide/profiles?format=md), мультиплексирование ✅ (https://hermes-agent.nousresearch.com/docs/user-guide/multi-profile-gateways?format=md), проекты ✅ (https://hermes-agent.nousresearch.com/docs/reference/cli-commands?format=md), AGENTS.md ✅ (https://hermes-agent.nousresearch.com/docs/guides/tips?format=md).

**Правило для 4 ГБ RAM:** **2 профиля, не больше**. Дальше делите проектами и навыками. Профиль на каждую тему — это лишняя память в обслуживании, лишние cron и путаница.

### 2.2 Структура под ваши задачи

├─ проект kp         (шаблоны КП)           ├─ проект digital   (техника, аккаунты)
├─ проект clients    (лиды СПб, CRM-файл)   ├─ проект home      (быт, покупки)
├─ проект site       (код сайта)            └─ проект plans     (неделя, цели)
├─ проект social     (контент-план)
└─ проект portfolio  (фото, кейсы)
```

### 2.3 Если выберете Telegram: супергруппа-форум вместо DM-топиков

Одна приватная супергруппа (вы и бот) с включёнными «Темами». Каждая тема — отдельная сессия: изоляция встроена ✅. Тема может сама подгружать навык (`group_topics`) и иметь свой короткий промпт (`channel_prompts`). Личные темы можно направить в профиль `life` через `profile_routes` по `thread_id` ✅. Чем это лучше DM-топиков: темы создаются и сортируются обычным интерфейсом Telegram, их удобно закреплять и отключать звук, а cron можно доставлять в отдельную тему.

```yaml
# ~/.hermes/config.yaml (профиль default)
telegram:
  require_mention: false          # в приватной группе не нужно @упоминать бота
  channel_prompts:
    "5": |
      Тема «Сметы». Ответ: таблица позиций + итог. Без вступлений.
    "9": |
      Тема «Финансы». Записывай расходы в учёт, отвечай одной строкой.

platforms:
  telegram:
    extra:
      group_topics:
        - chat_id: -1001234567890   # ID вашей супергруппы
          topics:
            - name: Сметы
              thread_id: 5
              skill: smeta-dveri
            - name: КП
              thread_id: 7
              skill: kp-pdf
            - name: Входящие (cron)
              thread_id: 3

gateway:
  multiplex_profiles: true
  profile_routes:
    - name: tg-finance
      platform: telegram
      chat_id: "-1001234567890"
      thread_id: "9"
      profile: life
```

`thread_id` берётся из ссылки на тему: `t.me/c/1234567890/5` — последнее число. ID супергруппы = `-100` + ID группы. Группу нужно добавить в `TELEGRAM_GROUP_ALLOWED_CHATS`, а боту дать права админа или отключить privacy mode ✅ (https://hermes-agent.nousresearch.com/docs/user-guide/messaging/telegram?format=md). ⚠️ Совместная работа `channel_prompts`, `require_mention` и `profile_routes` в одном конфиге не проверена: после применения проверьте `hermes gateway status` и логи.

### 3.2 Как работает сжатие ✅

- Срабатывает при `threshold` (по умолчанию **0.50 окна**) или раньше, если задан `threshold_tokens` (берётся меньшее из двух).
- Средняя часть диалога сворачивается в сводку вспомогательной моделью. Последние `protect_last_n` сообщений (20) и первые `protect_first_n` (3) не трогаются.
- `tail_mode: lean` (по умолчанию) хранит компактный хвост и указатели для `session_search`. Это примерно втрое меньше токенов после сжатия, чем режим `legacy`.
- `in_place: true` — сжатие внутри той же сессии.
- `proactive_prune_tokens` — бесплатная (без LLM) обрезка старых тяжёлых результатов инструментов.
- `idle_compact_after_seconds` — сжатие после простоя.
- Изменения `compression.*` применяются **со следующего сообщения**, без перезапуска.

Источник: (https://hermes-agent.nousresearch.com/docs/user-guide/configuration?format=md)

**Типичные ошибки:**
1. **У модели для сводки окно меньше, чем у основной.** Документация прямо говорит: середина диалога при этом **молча выбрасывается** без сводки ✅. Берите модель с окном ≥ основной: у DeepSeek V4 Flash 1 млн, как и у Pro.
2. **Порог 50% на модели с окном 1 млн** означает, что сжатие начнётся только на ~500 тыс. токенов, а каждый ход до этого стоит очень дорого. Обязательно задайте `threshold_tokens`.
3. Медленная «думающая» модель для сводки вызывает таймауты: Telegram рвёт соединение, и ход выглядит зависшим. Ставьте `reasoning_effort: low`.

Ручное сжатие:
- `/compress` — свернуть историю;
- `/compress focus <тема>` — свернуть с акцентом на теме;
- `/compress here N` ✅ (https://hermes-agent.nousresearch.com/docs/reference/slash-commands?format=md)

### 3.4 Готовый YAML (экономный профиль)

```yaml
# ~/.hermes/config.yaml — перед правкой: cp ~/.hermes/config.yaml ~/.hermes/config.yaml.bak
compression:
  enabled: true
  threshold: 0.50
  threshold_tokens: 60000          # сжимать не позже 60K, независимо от окна модели
  target_ratio: 0.20
  tail_mode: lean
  protect_last_n: 12               # было 20 — для чатов с телефона достаточно
  protect_first_n: 3
  in_place: true
  idle_compact_after_seconds: 3600 # сжать после часа простоя
  proactive_prune_tokens: 30000    # бесплатная обрезка старых тяжёлых выводов
  progress_notices: false          # не спамить «Compacting…»

auxiliary:
  compression:
    provider: nous
    model: deepseek/deepseek-v4-flash      # ⚠️ сверить точный id
    reasoning_effort: low
    timeout: 300
    fallback_chain:
      - provider: nous
        model: deepseek/deepseek-v4-pro-0813   # ⚠️ сверить id
    max_concurrency: 2
  vision:
    provider: nous
    model: google/gemini-3.1-flash-lite-preview # ⚠️ сверить id
    reasoning_effort: none
  title_generation:
    enabled: true
    model_upgrade_enabled: false   # заголовок без вызова модели = $0
    language: "Russian"
  approval:    {provider: nous, model: deepseek/deepseek-v4-flash}
  skills_hub:  {provider: nous, model: deepseek/deepseek-v4-flash}
  mcp:         {provider: nous, model: deepseek/deepseek-v4-flash}
  curator:     {provider: nous, model: deepseek/deepseek-v4-flash, reasoning_effort: low}
  background_review:
    enabled: true
    provider: nous
    model: deepseek/deepseek-v4-flash
    max_input_tokens: 40000        # жёсткий потолок на одно ревью

agent:
  disabled_toolsets:               # уточнить после /context all
    - homeassistant
    - spotify
    - discord
    - discord_admin

tools:
  tool_search:
    enabled: "on"                  # явно, чтобы поведение не поменялось после обновлений

tool_budget:
  mcp_result_size_chars: 30000

tool_loop_guardrails:
  loop_caps:
    max_web_searches: 15           # по умолчанию 50 за ход
    max_subagents: 3               # по умолчанию 50; под 4 ГБ RAM — 3

curator:
  enabled: true
  interval_hours: 168
```

Все ключи есть в документации ✅ (https://hermes-agent.nousresearch.com/docs/user-guide/configuration?format=md) (https://hermes-agent.nousresearch.com/docs/user-guide/features/tool-search?format=md). Блок `curator` взят из зеркала документации 🧪 (https://github.com/mudrii/hermes-agent-docs/blob/main/user-guide/features/curator.md).

Об идентификаторах моделей: в документации есть только формат `deepseek/deepseek-v4-pro` ✅. Точные id для Flash, 0813 и Gemini Flash Lite **надо сверить** ⚠️ — сообщение ниже это делает. `prompt_caching.cache_ttl` действует только для моделей Anthropic. ### 3.6 Привычки, которые экономят деньги
